# TryHackMe Notes — Week 1

## Cyber Kill Chain
1. Reconnaissance — collecter infos sur la cible
2. Weaponization — créer le payload/malware
3. Delivery — envoyer le payload (email, USB...)
4. Exploitation — déclencher la vulnérabilité
5. Installation — installer persistence sur la machine
6. Command & Control — canal de communication attaquant/cible
7. Actions on Objectives — but final (vol data, ransomware...)
